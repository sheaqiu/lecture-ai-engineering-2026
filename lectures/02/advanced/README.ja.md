# 第2回 Advanced：用語集を用いたLoRA実験

実験は公式英語版をforkして実行し、後から日本語版のforkへ提出資料を移しました。[出典と保存方針](../source_english/README.md) と [演習・課題レポート](../answer.md) を参照してください。

## 実験資材

- `glossary.json`：実験で使った英語の用語集58項目。
- `glossary_sft.jsonl`：講義の生成スクリプトから得た、変更前の116件の問答。
- `train.jsonl`：116件の回答を構造化し、未掲載用語8件を追加した学習データ124件。
- `valid.jsonl`：既知用語8件、未掲載用語4件の検証データ12件。
- `test.jsonl`：用語名の質問6件、言い換え6件、未掲載用語6件のテスト18件。
- `gold.json`：参照定義、確認フラグ、採点用キーワード。モデルの回答入力には渡しません。
- `advanced_glossary.py`：データ準備、採点と単純な用語検索。
- `manifest.json`：実験時の出典、変換方法、ファイルハッシュ。
- `README.md`：実行時のZIPに含まれる、実験準備時点の英語の説明。

モデルは定義を入力せずに回答し、比較用の検索処理は用語集を参照します。学習とテストで既知概念を共有しますが、質問文は重複していません。未掲載用語は各分割で別々に選びました。内容の自動採点はキーワードによる代替指標のため、元の回答と合わせて解釈します。

## 実行記録

私はColabで3エポック、48回の更新を実行し、学習時間は205.98秒でした。自動内容評価は学習前5/18、学習後7/18、単純検索15/18でした。学習前後のJSON形式は18/18でした。結果とログは [results/advanced](../results/advanced/) に保存しています。

再実行には [ノートブック](../../../notebooks/lora_glossary_advanced.ipynb) をT4 GPUのColabで開きます。ノートブックはこのディレクトリの固定資材を読み込み、ハッシュを照合します。言語変更によって既存の測定値を更新したわけではありません。
